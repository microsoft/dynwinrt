## Prerelease v0.1.0-preview.22

**Packages:**
- `@microsoft/dynwinrt` - JavaScript/TypeScript bindings for WinRT dynamic invocation
- `@microsoft/dynwinrt-codegen` - Code generation tool for typed WinRT bindings
- `dynwinrt` - Native Python runtime for generated WinRT projections
- `dynwinrt-codegen` - Standalone Python code generation tool

## Installation

```bash
npm install @microsoft/dynwinrt
npm install -D @microsoft/dynwinrt-codegen
python -m pip install --pre dynwinrt dynwinrt-codegen
```

## What's Included

- ✅ Native addons for x64 and ARM64
- ✅ TypeScript type definitions
- ✅ dynwinrt-codegen CLI for code generation
- ✅ CPython 3.11–3.14 runtime wheels for Windows x64 and ARM64
- ✅ Standalone Python codegen wheels for Windows x64 and ARM64

For usage instructions, see the [README](https://github.com/microsoft/dynwinrt#readme).
